Wonder Artwork — full source list
==============================================================================

Provenance for every picture in `public/assets/wonders/`.

Nine pictures (Colossus, Great Library, Hanging Gardens, Lighthouse, Oracle,
Magellan's Expedition, Shakespeare's Theatre, Leonardo's Workshop,
Super-Kamiokande) are supplied
by the project owner from their own collection. They have no external source,
so the game shows no image-source link for them — only the "Read more on
Wikipedia" link. The remaining sixteen come from Wikimedia Commons as
described below.

HOW EACH PICTURE WAS OBTAINED
  All images were downloaded from Wikimedia Commons through its public API
  (`action=query&prop=imageinfo&iiurlwidth=...`), which returns the
  thumbnail URL, the author and the licence in one response. Only freely
  licensed files were accepted:
      public domain  ·  CC0  ·  CC BY  ·  CC BY-SA
  Each download is the Commons-generated thumbnail, i.e. an unmodified copy
  apart from that downscaling (current files are roughly 1000–1600 px wide).
  The game only frames the files with CSS `object-fit`, which crops at
  display time and does not alter them.

WHERE THE CREDIT IS SHOWN IN-GAME
  `src/components/ui/gamemodals/WonderArtwork.tsx` renders a credit line
  under every image, containing:
    - a "Read more on Wikipedia" link to the article about that wonder
    - the author, linking to the Wikimedia Commons file page
    - the licence name, linking to the licence deed (when not public domain)
  Own artwork (the eight above) shows the article link only.
  Licence compliance is therefore satisfied in the build itself, not only here.

MACHINE-READABLE COPY
  The same data lives in `WONDER_ARTWORK_CREDITS` in
  `src/data/WonderData.ts`, so the UI never hard-codes a URL. When adding or
  replacing an image, update all three: `WONDERS[].image`, the credits table,
  and this file.

NOTES
  * No image was taken from Britannica. Britannica's encyclopedia photographs
    and illustrations are copyrighted and not released under a free licence, so
    they cannot be redistributed inside a game without permission from the
  rights holder. Freely licensed equivalents exist on Commons for all 23
  wonders (for space imagery, NASA material is in the public domain).
  * The Colossus of Rhodes, Hanging Gardens and Lighthouse are ancient and lost,
    so they use period reconstructions: Athanasius Kircher (1679) and
    Philip Galle (1572). These are the canonical historical depictions.
  * Images are fetched lazily — a wonder's picture is only downloaded once the
    screen showing it is opened and the frame scrolls into view.
