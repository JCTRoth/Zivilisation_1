= Technology Tree: This Game vs. Original Civilization I (1991)
:toc:
:toclevels: 2
:icons: font

This document maps every technology in this codebase
(`src/data/TechnologyData.ts`, 54 techs) to its counterpart in the original
Sid Meier's Civilization (1991), adds the facts a player actually needs
(cost, prerequisites, what the code *really* unlocks), a research
recommendation, and an honest comment on whether the tech's in-game text
tells the player what it does.

[IMPORTANT]
====
Unlock facts are verified against the code (`UnitConstants.ts`,
`BuildingConstants.ts`, `WonderData.ts`, `TileImprovementConstants.ts`,
`GovernmentManager.ts`). Where the in-game `description` disagrees with the
code, the *Unlocks* column wins — see the Clarity column for the mismatch.
The authoritative balance numbers remain in
link:GAME_RULES.adoc[Game Rules Reference].
====

== How to read the table

* ★ = root technology (no prerequisites; available from the start).
* *Original Civ1* uses the names from the original tech list as provided
  (some are non-English renderings, e.g. "Rad" = The Wheel, "Card
  production" = Cartography/Map Making, "Ceremonial funeral" = Ceremonial
  Burial). A dash (—) means the tech has no counterpart in that list.
* *Recommendation*: `High` — research early / near-must; `Med` — valuable
  for a matching strategy or as a path tech; `Low` — niche, only as a
  stepping stone or wonder chase.
* *Clarity*: how well the tech's name + in-game description explain its
  actual effect to a player: `Clear`, `Vague`, or `Misleading` (the
  description names something that does not exist or gates something else).

== Known text/documentation issues

Kept as a checklist for whoever next touches `TechnologyData.ts` or
`GAME_RULES.adoc`:

. Six in-game `description` strings name things the code does not gate:
  Horseback Riding → "Horsemen", Polytheism → "Horsemen", Monotheism →
  "Crusader units", Theology → "Cathedrals" (Monotheism gates them),
  Computers → "Research Labs", Literacy → "libraries" (Writing gates them).
  See the Clarity column above.
. link:GAME_RULES.adoc#_the_tree[Game Rules — The tree] omits 9 of the 54
  techs (Mysticism, Religion, Theory of Gravity, Magnetism, Medicine,
  Invention, Nuclear Fission, Automobile, Genetic Engineering) and still
  lists stale unlocks ("Great Wall", "United Nations", "Women's Suffrage")
  that exist nowhere in `src/data/`.
. link:GAMEPLAY.adoc[Gameplay] § "The actual tree" used to claim there is no
  *Invention* or *Nuclear Fission* in this codebase — both are in
  `TechnologyData.ts` (the claim has been corrected in place).
. Moonshot is unselectable in the tech-tree UI (`available: false`) and
  additionally gated behind the ISS; the table above documents the intent,
  not a UI path the player can click.
