[[overview]]
== 1. Overview

The diplomacy system implements a full diplomatic relations framework inspired by Sid Meier's Civilization I but significantly *extended* with modern 4X features:

=== Features from Civ I
* Four diplomatic states: Peace, Ceasefire, Alliance, War
* Diplomat unit with spy/bribe/proposal actions
* AI attitude calculation toward other civilizations
* Tribute demands and gold transfers
* Reputation tracking for treaty-breakers

=== Features beyond Civ I
* *Open Borders* — allow unit passage through foreign territory
* *Trade Agreements* — generate gold-per-turn for both parties
* *Mutual Defense Pacts* — automatic war declaration when an ally is attacked
* *Non-Aggression Pacts* — soft commitment against hostility
* *Embargoes* — jointly restrict a third civilization
* *Technology Exchange* — swap known technologies between civilizations
* *Knowledge for Gold* — sell a technology for a price, or buy one
* *Gifts of Knowledge* — hand a technology over for nothing, and be loved for it
* *Gold Transfers* — gift gold, or ask for it: a friend gives, a rival pays
* *Calls to Arms* — an ally can be called to fight, defensively or offensively
* *Counter-Proposals* — AI rejects an offer but suggests alternative terms
* *Border Friction* — nearby cities worsen attitude automatically
* *Alliance Cascade* — attacking an ally drags their allies into the war
* *Fixed Alliances* — an optional setup-time mode that locks civilizations
  into permanent teams above the ordinary pair-based diplomacy
* *Procedural Leader Portraits* — SVG-rendered portraits with mood expressions

[[diplomatic-states]]
== 3. Diplomatic States

Every pair of civilizations has exactly one `DiplomaticStatus`:

[cols="1,2,1", options="header"]
|===
|Status |Description |Icon

|`'alliance'`
|Full alliance — shared goals, mutual aid possible
|🤝

|`'peace'`
|Default state — no hostilities, normal relations
|🕊️

|`'ceasefire'`
|Temporary halt to fighting; a signed peace blocks re-declaration for 8 rounds
|🏳️

|`'war'`
|Active hostilities — units can attack, AI targets enemy
|⚔️
|===

=== State transitions

[source]
----
         ┌──────────────────────────────┐
         │                              │
         ▼                              │
    ┌─────────┐   propose_alliance   ┌──┴──────┐
    │ ALLIANCE │◄────────────────────│  PEACE   │
    └────┬────┘                      └──┬──┬───┘
         │                              │  │
         │ break alliance               │  │ declare_war
         │ (penalty -50)                │  │ (penalty -20)
         │                              │  │
         ▼                              │  ▼
    ┌─────────┐   propose_peace      ┌──┴──────┐
    │  PEACE   │◄────────────────────│   WAR    │
    └─────────┘                      └──┬──────┘
         ▲                              │
         │        propose_ceasefire     │
         │       ┌───────────┐          │
         └───────│ CEASEFIRE  │◄────────┘
                 └───────────┘
                   (5 turn cooldown)
----

=== Opinion: a directed ledger, not a reputation score

There is no single reputation number. Each civ keeps a directed **Opinion**
per pair — `goodwill` (−100..100), `grievance`, `fear` and `respect` (0..100) —
in `src/game/engine/diplomacy/DiplomaticOpinion.ts`. Every act is an
`ImpactEvent` with a base delta from `DiplomaticImpacts.ts`, scaled by
personality weights and the current state, and written into the direction it
happened in. Base goodwill values:

[cols="1,1"]
|===
|Action |Goodwill

|Betraying an alliance (`alliance_break`)
|-60

|Losing a unit to a bribe (`unit_bribed`)
|-45

|Surprise attack (`surprise_attack`)
|-35

|Breaking a ceasefire (`ceasefire_break`)
|-30

|Caught spying / cancelling a treaty
|-20 / -6

|Common enemy defeated / technology exchanged
|+15 / +10

|Alliance formed / trade agreement signed
|+10 / +7
|===

Personality is a **weight vector**, not an offset: the same betrayal costs a
paranoid diplomatic civ about 2.5× what it costs a belligerent one. Grievance
decays at 0.5 per turn; goodwill changes only through acts. A signed peace arms
an 8-round cooldown before the AI considers war again.

The ledger survives save/load — that migration is the v3 → v4 save bump.

[[treaties]]
== 4. Treaties (Beyond Civ I)

In addition to the basic diplomatic status, civilizations can sign *treaties* that add specific agreements on top of any peaceful status:

[cols="1,1,2", options="header"]
|===
|Treaty |Type Key |Effect

|*Open Borders*
|`'open_borders'`
|Allows unit passage through each other's territory

|*Trade Agreement*
|`'trade_agreement'`
|Both civs receive gold per turn (default: +2 gold/turn each)

|*Mutual Defense Pact*
|`'mutual_defense'`
|If one party is attacked, the other auto-declares war on the aggressor

|*Non-Aggression Pact*
|`'non_aggression'`
|Soft commitment not to attack; improves attitude score

|*Embargo*
|`'embargo_target'`
|Both parties jointly restrict trade with a specified third civilization
|===

=== Treaty rules

* *Cannot sign treaties during war* (except `non_aggression` after ceasefire)
* *No duplicate treaties* — signing the same treaty twice is a no-op
* *War invalidates all treaties* except embargoes
* *Cancelling a treaty* costs goodwill (`treaty_cancelled` = −6 base)
* *Each treaty writes goodwill directly* into the ledger when signed, scaled by
  personality: `trade_signed` +7, `alliance_formed` +10, `open_borders_signed`
  +3, `mutual_defense_signed` +8, `non_aggression_signed` +5

[[attitude-reputation]]
== 5. Attitude & Reputation System

=== Attitude levels

[cols="1,1,1", options="header"]
|===
|Attitude |Score Range |Color

|`'friendly'`
|≥ 15
|Green `#4caf50`

|`'neutral'`
|-5 to +14
|Grey `#9e9e9e`

|`'annoyed'`
|-20 to -6
|Orange `#ff9800`

|`'hostile'`
|≤ -21
|Red `#f44336`
|===

=== How the ledger is built

There is no single attitude formula. Every act is one ledger write whose base
delta comes from `DiplomaticImpacts.ts` and is then scaled:

[source]
----
delta = base_impact(act)      # e.g. alliance_break = −60
      × personality_weight    # loyalty, paranoia, greed, …
      × state_modifier        # what the two civs currently are to each other
      × magnitude             # a 500-gold demand is not a 5-gold demand
goodwill = clamp(goodwill + delta, −100, 100)
----

The attitude *bands* above are derived from the resulting goodwill. Fear and
respect come from the military-strength comparison; border friction adds
`border_pressure` impacts over time instead of a flat −8/−3 term.

[[diplomat-actions]]
== 6. Diplomat Unit Actions

The *Diplomat* is a civilian unit (attack: 0, defense: 0, movement: 2, cost: 30) that can perform diplomatic actions when adjacent to an enemy unit or city.

==== What a diplomat can do, and where the list comes from

`GameEngine.getDiplomatTargets(diplomatId)` returns one `DiplomatTarget` per
adjacent foreign city *and* per adjacent foreign unit — a diplomat standing
between two courts may choose which one to open with, and the unit menu
(`UnitActionsModal`) shows a chooser when there is more than one. Each target
carries `actions`: the complete list of abilities the diplomat has *there, right
now*.

That list is computed by `diplomacy/DiplomatAbilities.diplomatActionsFor` from
four facts — the target's kind, the diplomatic status, whether an embassy
exists, and which treaties are already in force — plus whether anything is
actually tradeable. The same list is what

* the player's menu is drawn from,
* the AI chooses from (`AIManager.chooseDiplomatContact` → `chooseDiplomatAction`),
* and `GameEngine.executeDiplomatAction` validates against before doing anything.

so the three doors in cannot disagree about what is legal. Previously the menu
drew a fixed list of eleven buttons regardless of context (most of which failed
with "diplomat action failed"), the engine offered ten and implemented nine, and
the six treaty terms below were reachable only from the diplomacy screen.

Rules the list encodes:

* the negotiation follows the status — war → ceasefire / peace / tribute;
  ceasefire → peace; peace → alliance / tribute; alliance → tribute;
* a city inside a *war zone* offers no infiltration and no embassy: a city you
  are fighting is entered with soldiers, not with a forged letter;
* terms beyond the basic statuses (`offer_open_borders`,
  `propose_trade_agreement`, `offer_tech_exchange`, `propose_mutual_defense`,
  `propose_non_aggression`, `propose_embargo`) require an *embassy* — the same
  gate the negotiation screen uses — and are not offered again once signed;
* `propose_embargo` additionally requires a third party to name, and
  `offer_tech_exchange` requires that both sides hold something the other lacks;
* `bribe_unit` belongs to a unit and the infiltrations to a city.

Terms the caller does not specify are filled in by the engine, so a bare
`executeDiplomatAction` still reaches the responder as a complete proposal: a
demand is worth 50 gold, a trade deal pays 2 gold/turn, an exchange names a
concrete pair of technologies and an embargo a concrete third party (a shared
enemy if there is one, otherwise the weakest other civ met). The negotiation
screen opens on the other side of the call, where the player names their own
terms or refuses outright.

[cols="1,2,2", options="header"]
|===
|Action |Description |Success factors

|`propose_peace`
|Offer to end a war
|Attitude + willingness roll

|`propose_ceasefire`
|Offer temporary ceasefire
|Easiest to accept (+20 willingness)

|`propose_alliance`
|Propose full alliance
|Hardest (-10 willingness)

|`demand_tribute`
|Demand gold payment
|Military strength ratio matters

|`bribe_unit`
|Spend gold to convert an enemy unit
|Cost = 25 × (attack + defense); 60% base chance

|`gather_intelligence`
|Generate spy report on enemy civ
|Always succeeds

|`offer_open_borders`
|Propose open borders treaty
|Attitude-based

|`propose_trade_agreement`
|Propose mutual trade income
|+10 willingness bonus

|`offer_tech_exchange`
|Swap technologies
|Both sides must have offered/requested tech

|`propose_mutual_defense`
|Propose defense pact
|-15 willingness (big commitment)

|`propose_non_aggression`
|Propose non-aggression
|+15 willingness (easy to accept)

|`propose_embargo`
|Jointly embargo a third civ
|-10 willingness
|===

=== Espionage (city infiltration)

Four more actions run *inside* an enemy city. Civ I rule: you infiltrate a city
you are *not* fighting — none of these are offered while the two civs are at
war, because a city inside a war zone is entered with soldiers, not with a
forged letter.

[cols="1,2,2", options="header"]
|===
|Action |Description |Outcome

|`establish_embassy`
|Open a diplomatic channel
|Always succeeds at peace; unlocks the negotiation screen for that court
(`DiplomacyManager.hasEmbassy`); announced via `EMBASSY_ESTABLISHED`

|`investigate_city`
|Read a city's internals
|Returns a `CityIntelligence` report (population, buildings, production,
shields banked) and touches nothing

|`industrial_sabotage`
|Wipe the shields a city has banked
|Detection roll: 50% base, ±6 per paranoia point; a caught saboteur has its
cover blown and starts a war, leaving the city untouched

|`steal_technology`
|Take ONE blind random technology
|Pool = `getTechTradeOptions().theyHaveWeLack`; detection roll 45% base. Civ I:
|the cover is *always* blown and the victim *always* declares war — the loot
lands only when the theft itself succeeded
|===

Detection is seeded per `(operative, target, kind, round)` via
`seededNoise`, so a replay resolves identically. Both infiltrations write a
real negative impact on the victim's ledger (`technology_stolen` −25,
`city_sabotaged` −18, `spy_detected` −20), scaled by the victim's paranoia or
vengeance.

=== Embassies

`DiplomacyManager.embassyPairs` records which pairs have a channel, keyed like
`relations` and persisted in the save as `diplomacyEmbassies`. An embassy is
the gate on the whole negotiation screen (see <<ui-diplomacy-modal,§12>>): without
one the rival is still *listed* — you have met them — but their ledgers read
"Unknown" and no term can be tabled. It also gates the AI's own tech offers:
`AIDiplomacyPolicy` refuses to propose an Exchange of Knowledge
(`hasEmbassy === false`), so knowledge only moves through a working channel —
and an AI *diplomat unit* is held to the same gate, because it chooses from the
same `getDiplomatTargets` menu the player's is drawn from
(`AIManager.chooseDiplomatTreaty` filters its scored candidates against that
list).

=== Willingness calculation

[source]
----
base = attitude_base[attitude]    # friendly: 75, neutral: 50, annoyed: 30, hostile: 10
+ action_modifier                 # see table above
+ military_strength_bonus         # +25 if proposer is much stronger (for tribute)
- treaties_broken × 15            # each broken treaty reduces willingness
= final willingness (clamped 0–100)

Roll: random(0–100) < willingness → accepted
----

[[ai-diplomacy]]
== 7. AI Diplomacy Logic

The AI evaluates diplomatic options every *5 turns* (`AI_DIPLOMACY_INTERVAL`):

=== Decision tree per relation

[source]
----
IF at war:
  IF outmatched (enemy > own × 1.3) AND war > 5 turns:
    → Propose ceasefire
  ELSE IF war > 15 turns AND attitude ≠ hostile:
    → Propose peace

ELSE IF at peace or ceasefire:
  IF aggression ≥ 7 AND own strength > enemy × 1.5 AND hostile:
    → Declare war
  ELSE IF aggression ≥ 6 AND own strength > enemy × 2 AND 10+ turns:
    → Demand tribute (scaled by strength ratio)
  ELSE IF at peace AND friendly AND diplomacy ≥ 6 AND similar strength:
    → Propose alliance
----

=== Player notifications

When AI diplomatic actions target a human player, `DIPLOMACY_EVENT` notifications are emitted with descriptive messages that appear as toast notifications in the UI.

[[alliance-cascade]]
== 9. Alliance Cascade & Mutual Defense

=== Alliance cascade (on combat)

When a unit attacks another civilization:

. The attacker auto-declares war on the defender (if not already at war)
. All *allies of the defender* automatically declare war on the attacker
. Each alliance cascade generates a `DIPLOMACY_EVENT` notification for human players

=== Mutual defense pact (on turn processing)

Each turn, the `processTurn()` method checks all mutual defense treaties:

. For each mutual defense pair (A, B):
** If A is at war with X, and B is NOT at war with X → B declares war on X
** If B is at war with Y, and A is NOT at war with Y → A declares war on Y

This creates a web of alliances that can escalate conflicts realistically.

[[fixed-alliances]]
=== Fixed alliances (locked teams)

Fixed alliances are an optional setup-time game mode. They are *not* a fifth
diplomatic status: `TeamManager` holds a locked membership layer above the
ordinary relation table, and every teammate pair is forced to a permanent
alliance.

* `TeamManager` is the single source of truth; `Civilization.teamId` is only a
  denormalised copy for the UI and the save file.
* `DiplomacyManager.applyTeamInvariants()` forces `alliance`, an embassy, open
  borders and contact for every teammate pair, and clears stale wars/embargoes.
* `declareWar`, `makePeace` and `signCeasefire` expand across the cross-product
  of both teams. A war with one member is a war with the whole team; the
  `WAR_DECLARED` event and the reputation hit are emitted once per team war.
* `getEnemyTeamCount()` counts distinct enemy teams, and
  `estimateTeamStrength()` sums every member's military strength, so the AI's
  war cap and target selection see a coalition as one opponent.
* Teammates may still trade, gift gold and exchange or sell knowledge. Hostile
  actions (war, break alliance, tribute, bribe, spy, sabotage, steal tech,
  incite revolt) and redundant pacts (alliance, peace, ceasefire, open borders,
  mutual defence, non-aggression, joint war, call for help, embassy) are refused
  at the proposal and diplomat-action chokepoints.
* Treaties that are part of the lock (`open_borders`, `mutual_defense`,
  `embargo_target`) cannot be cancelled with a teammate.
* Alliances and treaties with civilizations *outside* the team remain per civ.
  A team war overrides an ordinary alliance with an enemy civilization: the
  alliance breaks and the whole team is at war.
* AI policy, diplomat menus, enemy scanning and strength estimates are all
  teammate-aware.

Team victory, defeat and human spectating are documented in
link:FIXED_ALLIANCES.adoc[Fixed Alliances]. Teammates share vision, explored
ground and diplomatic contact within the team.

[[trade-economy]]
== 10. Trade & Economy

=== Trade agreements

* Both parties receive *+2 gold/turn* (configurable per agreement)
* Gold is transferred automatically during `processTurn()`
* Breaking a trade agreement (cancel or war) stops the income immediately
* Trade agreements are always *symmetric* — both sides benefit equally

=== Tribute

* Tribute demands extract gold from the target's treasury
* AI demand amount scales with military strength ratio: `max(25, floor(ratio × 20))`
* Weaker targets are more likely to comply (+25 willingness when outmatched ×1.5)

=== Bribery

* Unit bribe cost: `BRIBE_UNIT_BASE_COST (25) × (attack + defense)`
* Bribed unit changes ownership immediately (moves set to 0)
* Base 60% success chance, modified by attitude: friendly +20%, hostile -20%

=== Knowledge: swapping, selling, giving

Three shapes, one action family, and the *terms* decide which is which:

[cols="1,2,2", options="header"]
|===
|Shape |Action |Who pays the gold

|Swap
|`offer_tech_exchange` (a technology each way)
|The proposer, as a sweetener

|Sale
|`offer_tech_for_gold` (a technology one way, plus a price)
|Whoever hands the knowledge over — the money is the *price*, so it runs the other way

|Gift
|`gift_technology` (a technology, no money)
|Nobody
|===

The direction is decided in one place — `goldPayerFor()` in `DiplomacyTypes.ts` — so the engine and the scoring can never disagree about who pays.

* A technology is only ever handed to a civilization that does *not* know it yet.
* Knowledge changes hands *face to face*: a negotiated exchange needs both diplomats
  standing within reach of each other (`hasDiplomatContact`). A deal made in person —
  a unit standing at the other court's own doorstep, as in a trade visit — carries the
  knowledge with the messenger, and is flagged `inPerson` on the proposal.
* The AI deals in all three shapes too: `AIDiplomacyPolicy` scores them, and
  `pickTechGiftTerm` / `pickTechForGoldTerm` name the terms.

=== Gold: giving, asking, and the two ways an ask lands

* `gift_gold` — the responder *keeps* the money. A gift is not a negotiation, so it is
  accepted even by a court that dislikes the giver: the point of sending it is to win
  that court over. It improves the receiver's opinion of the giver on both ledgers.
* `request_gold` — the responder *pays*. It lands for one of two reasons, and the
  scoring names both:
  * *friendship* — a good relationship makes the ask hard to refuse;
  * *fear* — a threatening army (and the fear meter that tracks it) makes it cheaper
    to pay than to fight.
  Personality scales both: a trusting court weighs friendship more, a suspicious one
  weighs fear more. Asking for more than the payer can spare is refused on that ground
  alone.
* Which of the two it was is remembered: a payment made under duress is written on the
  ledger as tribute (`tribute_extorted`), one made out of friendship as a kindness
  (`tribute_gift`). `isCoercedPayment()` decides, by the balance of power.
* The AI asks for money on the same terms — a modest sum from a friend, a much larger
  one from a rival it can threaten — and the player answers in the audience screen.

=== Calls to arms

* When a civilization is attacked, it calls every ally it has: a mutual-defence partner
  *or* a plain alliance partner (`isAllyOf`).
* The same call exists offensively: before attacking, a civ asks its allies to join.
* The ally weighs the call like any other war — no capacity for another front, worn
  down from war, or an enemy that outclasses it, and it says no. A refusal breaks the
  mutual-defence pact and is remembered as `ally_abandoned`.
* The call is *one ring deep*: an ally that joins a war does not set off another round
  of calls of its own (`declareWar(..., { propagateCalls: false })`), so one war cannot
  walk the whole alliance network.

=== The embassy gate

The whole terms block is locked until the player has an embassy with that
court. Without one:

* the rival still appears in the roster (they have been *met*),
* the goodwill/grievance/fear ledger is replaced by a single italic line
  (`.diplomacy-locked-value`) explaining there is no channel yet,
* the terms section is replaced by `.diplomacy-embassy-gate` — an "Embassy
  required" badge plus the hint to station a diplomat in their city,
* "Advanced Treaties" (including the Exchange of Knowledge pickers) does not
  render at all.

The audience card carries a chip (`.diplomacy-embassy-chip`) showing either
"🏛️ Embassy established" or "🔒 No embassy", so the state is visible without
scrolling to the terms.

[[ui-audience]]
== 12a. UI — Audience Screen

`AudienceModal` (`src/components/ui/gamemodals/AudienceModal.tsx`, dialog id
`audience`) is what a *unit meeting unit* opens: a rival leader received across
a dark hall, with one plain choice at the bottom. It is deliberately not the
negotiation screen — no columns of numbers, no ledger, no term pickers.

Two ways in:

* *Greeting* — the player picks "Meet with Leader" from a diplomat's action
  menu. Nothing is proposed; the leader receives you and you may leave.
* *Offer* — an AI civ puts its own proposal to the player
  (`AI_DIPLOMACY_OFFER` → `EngineEventRouter.onAIDiplomacyOffer` →
  `actions.openAudience`). The player answers Yes/No; there is no way to
  counter-offer from this screen.

Layout: a large pixel portrait tuned to how they feel about you (`mood`
drives a colour wash and a mood-tuned filter — the artwork is fixed, so the
mood is carried by light), the leader's name and attitude badge, a speech field
(green for an offer, grey for a formal audience), and the choice list in
Civ I's blue.

`IncomingDiplomacyOffer.message` used to be dropped on the floor here — the
audience screen is what it was for. Tech-exchange and tribute lines are
rebuilt from the terms in the player's language rather than passing the
engine's English sentence through.

=== API

[source]
----
openAudience(notice: AudienceNotice)   // GameStore — opens dialog 'audience'
clearAudience()                        // closes it and drops the notice
----

`AudienceNotice` (`types/game.ts`): `{ civId, mode: 'offer' | 'greeting',
action?, goldAmount?, techOffered?, techRequested?, message }`.

The screen defers auto-end-turn like every other decision screen
(`EngineEventHandlers.isDecisionScreenOpen`), and dismissing it re-checks.

[[leader-portraits]]
== 13. Leader Portraits

=== Procedural SVG portraits

Each leader is rendered as a procedural SVG in `LeaderPortrait.tsx`. The portrait consists of layered SVG elements:

. *Scene background* — throne room, temple, tent, palace, garden, fortress, or court
. *Body & clothing* — colored ellipses with accent details
. *Head & skin* — elliptical head shape with skin tone
. *Hair* — behind-head ellipse
. *Eyes* — white sclera + colored iris + dark pupil
. *Eyebrows* — mood-reactive angle (raised = friendly, angled down = hostile)
. *Nose & mouth* — mouth curve changes with mood (smile/frown/straight)
. *Facial hair* — beard, mustache, or goatee (per leader config)
. *Headgear* — crown, top hat, helmet, turban, pharaoh nemes, laurel wreath, headdress, fur cap, or Napoleon-style hat

=== Mood expressions

The portrait visually reacts to the leader's current attitude:

[cols="1,1,1", options="header"]
|===
|Mood |Mouth |Eyebrows

|Friendly
|Upward curve (smile)
|Slightly raised (+1.5°)

|Neutral
|Straight line
|Level (0°)

|Annoyed
|Straight line
|Slightly lowered (-1.5°)

|Hostile
|Downward curve (frown)
|Steeply angled (-3°)
|===

=== Replacing SVG with actual images

The system is designed so *procedural portraits can be replaced with pixel art or painted images*: drop the artwork in, point `LeaderPortraits.ts` at it, and the mood-driven theming above keeps working unchanged.

Events are routed through `EngineEventRouter.handle()`:
* `WAR_DECLARED` → notification toast + state sync
* `PEACE_MADE` → notification toast + state sync
* `DIPLOMACY_EVENT` → notification toast with the AI's message
