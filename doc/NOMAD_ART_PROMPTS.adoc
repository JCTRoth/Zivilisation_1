= Nomad Faction Art — Generation Prompts

> The prompts now live with the factions themselves, so history, temperament
> and art are documented in ONE place:
>
> → link:../src/game/engine/nomad/FACTIONS_README.md[`src/game/engine/nomad/FACTIONS_README.md`]
> — the three peoples (Bedouin / Mongol / Sámi), how they play, the shared
> style block and one prompt per faction.

== Art slot

[cols="2,3", options="header"]
|===
|File |Shown by

|`public/assets/nomads/<id>.png` |The generated portrait (512×640, PNG, dark background baked in). Tried first — drop it in and it appears, no code change.

|`public/assets/nomads/<id>.svg` |The built-in poster shipped with the game (see `public/assets/nomads/*.svg`). Shown until a PNG exists.

|the faction emoji (🐫 / 🐎 / 🦌) |Last resort, if neither file loads.
|===

Both the audience dialog and the diplomacy hall render the same slot
(`src/components/ui/ClanPortrait.tsx`), so one generated file upgrades both
screens at once. A failed load is non-fatal at every layer.
