=== 1. Naval Invasion / Transport Missions — DONE
The mission layer is implemented: `InvasionMission` (interface at
`AIManager.ts:284`, plan/access at `:3378-3382`, ferry action `:3749`,
stored per turn at `:3321`), beach scoring, real load/unload through the ferry
APIs, beachhead holds and batch counters (`Invasion —`, `AIManager.ts:3497,
3798`). Regression tests: `tests/ai/navalInvasionSequence.test.ts`,
`aiNavalTransport.test.ts`, `aiInvasionPlanning.test.ts`. Recorded as DONE in
`TODO/TODO.txt:112-114` (moved to TOBECHECKED for a game run). *Remaining:*
only the Civ1 transport-backend spec rules in `TODO/TODO.txt` are still to be
checked against a real game run.

=== 2. Multi-Group Offensives / Siege Commitment — mostly done
`AIManager.secondaryGroupTargets` (`AIManager.ts:726`) lists the committed
plan's target first and then opens at most `MAX_SECONDARY_FRONTS = 2`
(`:731`, used at `:1028`) secondary fronts on the same war's other cities, so
groups coordinate instead of stacking beside the main siege
(`tests/ai/armyComposition.test.ts`). *Remaining:* pincer/encirclement
scripting and a third group (`TODO/TODO.txt:40-43`).

=== 3. Army Composition by Era — DONE
`AutoProduction.bestBuildableDefender` / `bestBuildableAttacker`
(`AutoProduction.ts:1735,1752`) pick from `UNIT_PROPS` by role and
`canBuildUnit(civ, type)` — no hardcoded ladder, so `mech_inf` and tanks are
fielded the moment the tech lands, and defenders mix in the era's best
attacker every third garrison unit. Tests: `tests/ai/armyComposition.test.ts`.

=== 4. Economy Buildings Earlier — DONE
Economy buildings are valued against upkeep pressure and the treasury by
`src/game/engine/AI/BuildingCoordinator.ts` and
`src/game/engine/AI/BuildingEconomics.ts` (gain − upkeep per turn), so
Marketplace/Bank/Temple are ordered when upkeep starts to bite instead of
after the treasury is empty.
