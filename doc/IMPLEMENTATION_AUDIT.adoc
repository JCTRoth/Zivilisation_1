= Implementation Audit — What Is Done, Partial and Missing
:date: 2026-11-07
:toc: macro
:toclevels: 2

Audit of the whole project (engine, AI, UI, data, docs, CI scripts) against
``TODO.txt``, ``README.adoc`` and the ``doc/*.adoc`` claims. Every status below
was verified against code (file/line evidence), not against documentation.

Method: six parallel source audits (gameplay fidelity, diplomacy/espionage, AI,
wonders, systems/infrastructure, UI/rendering), plus direct verification runs of
`npm run test`, `npm run type-check`, `npm run lint` and `npm run knip`.

*Re-audit 2026-11-07:* every status below was re-checked against the code, and
all four gates were re-run: `npm run test` → **247 files / 2 929 tests, all
passing**; `npm run type-check`, `npm run lint` (`--max-warnings 0`) and
`npm run knip` each exit 0 with no findings.

  2 929 tests pass** (re-run 2026-11-07) — the same number the README quotes
  ("247 suites / 2,929 cases").

== 2. Done (verified working)

=== Core gameplay

* 14 civilizations with leaders, portraits, city-name lists; AI personalities.
* 36 unit types across land/sea/air/civilian (including the Trade Ship);
  stacking, GoTo, sleep / fortify / skip / wait; embark/ferry cargo with
  capacity and cargo-death-on-sink.
* City founding, joining, capture, destruction, razing, governors, specialists;
  growth, starvation, granary (keeps half the food box on growth), disorder,
  martial law; housing cap: Aqueduct gates growth at 10
  (`EconomicManager.ts:171`, `TurnManager.ts:1409-1420`).
* Specialists fully implemented: map icons under the city
  (`getCitySpecialistButtons`), left/right click assign/remove, side-panel
  tally, default entertainer for unassigned citizens, tests
  (`tests/specialists.test.ts`, `tests/idleCitizens.test.ts`).
* Combat: win chance model, terrain defence, fortify/city bonuses, walls ×1.5,
  garrison rounds, city capture consequences; **splash damage** in engine
  (`CombatSystem.splashDamage`, `GameEngine.applySplashDamage:6086`) with
  city/fortress/fortified/embarked immunities, and the **AI is splash-aware**
  (de-stacking, `AITactics.scoreStackTarget`, `AIManager.deStackStep`).
* **Veteran ranks**: Rookie → Trained → Seasoned → Battle-Hardened (×1.0–×1.5),
  XP awards, Barracks seeding, UI badges, tests (`UnitRankSystem.ts`).
* Healing in cities: +2 HP/turn up to 15 % of battle damage, ⚕ symbol on the
  map (`CombatSystem.ts:47-54`, `MapRenderer.ts:407-416`).
* Pollution (nuclear plants, strikes, cleanup, score penalty, demographics
  metric), nuclear plants meltdown, barbarians, goody huts / villages,
  tile improvements, rivers (fordable-width rules centralised in
  `RiverRules.ts`) and lakes (enclosed < 24 tiles, impassable).
* **Random disasters**: all 7 Civ1 city disasters (famine, flood, fire, plague,
  **pirates**, volcano, earthquake) with per-kind odds, prevention (Granary/
  Barracks/Aqueduct/Temple rules), population loss and gold robbery
  (`DisasterManager.ts`, wired into the city turn at `TurnManager.ts:959`,
  `CITY_DISASTER` event + toast, tests `tests/disasters.test.ts`).
* Fog of war with per-player visibility, explored memory, save/load restore.
* Victories: Moonshot (research) and elimination — including the settler rule:
  a civ losing its last city survives only if a settler remains, other units are
  removed (`GameEngine.applyLastCityRule`, `GameEngine.ts:6711`).

=== Wonders (24, data-driven)

* 24 wonder definitions with artwork (`src/data/WonderData.ts`), effects wired
  into economy/happiness/science/ship movement/vision/anarchy/upgrades/nukes,
  obsolescence gated by *any* civ's tech, global uniqueness, lost-race
  progress removal, cannot sell, ownership transfers on capture.
* UI: celebratory completion modal (artwork + effect + lore), Wonders overview
  with status colours, production-conflict modal (Go to City / Close), city
  screen Wonders section, per-wonder Civilopedia modal, availability gating in
  the production picker; 8 dedicated test files.
* **Spaceship gate (was the "partial known bug", now fixed):**
  `WonderEffects.computeGlobalGate` (`WonderEffects.ts:97-126`,
  exported as `computeSpaceshipEnabled` at `:122`) reads the `enableSpaceship`
  effect from *any* built wonder — ISS, Tiangong and Mir all open the Moonshot;
  regression tests at `tests/wonderEffects.test.ts:290-303`.

=== Economy, trade, resources

* Yields, corruption (courthouse cuts it by 20 % — `corruptionReduction: 0.8`,
  `BuildingConstants.ts:114`), rates, food, happiness, upkeep per
  unit type, bankruptcy, trade → gold ×2.
* Trade routes + caravans with a full caravan governor
  (`CaravanGovernor.ts`, `CaravanCoordinator.ts`, doc + tests).
* Fisher Boat system with both TODO rules enforced: a net may not be deployed
  on a tile worked by any city, nor on a tile that already has a net
  (`GameEngine.canDeployFishingNet:3513`); auto outbound/fishing/inbound
  route, fish food formula, Harbor requirement, one boat per city.
* **Trade Ship** unit (`UnitConstants.ts:592`) — the Civ1 trade-ship role is a
  real buildable civilian unit, not a placeholder.
* **River fish**: fish spawn on rivers as well as coastal ocean — rivers roll
  at 0.09 (half the 0.18 coastal chance: `TerrainConstants.ts:324,343,353-356`,
  applied in `MapGenerator.ts:1349-1356`).

=== Diplomacy and espionage

* 4 statuses + 6 treaty types (`open_borders`, `trade_agreement`,
  `mutual_defense`, `non_aggression`, `embargo_target`, `embassy` —
  `DiplomacyTypes.ts:125`), directed goodwill/grievance ledger with
  personality-scaled impacts, proposal scoring, war wear, parallel-war limits,
  peace cooldown (8 rounds), consent-based mutual-defence honouring.
* Tech-for-tech exchange: engine, UI and AI proposals
  (`DiplomacyManager.ts:1418,2695`, `TechTradeEvaluator.ts`,
  `GameModals.tsx:1314-1380`, tests); tech-for-money via `offer_tech_for_gold`
  with a price input, and player gold gifts/requests (`gift_gold`,
  `request_gold`, plus the unprompted `offer_gift` button —
  `GameModals.tsx:804-805,868-870,1887,1947-1953`).
* Embassies (establish/gate UI), sabotage, steal technology, AI espionage
  policy, espionage report modal.
* AI diplomacy: demand tribute, nuclear-threat gold extortion (AI → player),
  AI-AI treaties/ceasefires/alliances happen and end (batch-measured).

=== AI

* Naval invasion / transport missions **are implemented** (the older docs in
  this repo claimed otherwise): `InvasionMission` gather/sail/siege,
  beach scoring, real load/unload via ferry APIs, beachhead holds, reservations,
  regression tests, batch counter `Invasion —`.
* Army groups (form/rally/march/attack, retreat morale), colony missions,
  forced building sales with funding planner, economy-building weights under
  upkeep pressure, nuclear production + strikes + sub delivery, scouting via
  engine GoTo with unexplored avoidance, systematic naval scouting, city
  governor (food → contentment → specialists), final war when no enemies
  remain, unreachable-area detection → navy pivot, no-settle-inside-own-radius
  rule, infrastructure planner (irrigation/roads from size 6, full coverage 12).

=== Systems, UI, infrastructure

* i18n: 6 languages (en/de/fr/es/ja/ru), 2 088 keys each, 0 missing/extra,
  language switcher, browser-language detection, wonder lore in all 6
  languages, enforced by tests. (Engine-composed strings remain English — see
  partial list.)
* Save/load: versioned JSON v5 with v1–v5 migrations, round-trip tests.
  One inconsistency to know about: the engine's `loadGame()`
  (`GameEngine.ts:9185`) accepts versions 1–5, but the App's *file picker*
  rejects anything that is not 1/2/3 (`App.tsx:719`), so an uploaded v4/v5
  `.json` is refused even though the engine would load it (autosave/manual
  saves go through localStorage and are unaffected).
* Command layer exists (`types/commands.ts`, `GameEngine.submit`,
  `GameSession`); 6 commands implemented (`MOVE_UNIT`, `SET_RATES`,
  `SET_CITY_PRODUCTION`, `FOUND_CITY`, `TEAM_COORDINATE_ATTACK`,
  `TEAM_DEFEND_CITY`).
* Autosave: every turn end writes a separate save slot `civ1_autosave`
  (`App.tsx:486-488`), so the manual save is never clobbered.
* Hot-seat / multi-human: the setup screen derives `humanSeats` and a
  `hotseat` game mode for 2+ humans (`GameSetupModal.tsx:693-702`), the turn
  engine pauses and emits `HANDOFF` for the next human (`TurnManager.ts:715-736`)
  and `HotseatHandoffScreen` asks for the pass-the-device confirmation;
  `skipHotseatHandoff` bypasses it. Automatic end-of-turn waits 3 seconds
  before switching players (`App.tsx:531-536`).
* Headless batch runners + progression CSV/JSON export; seeded URL scenarios;
  AI-vs-AI spectator mode.
* UI: unit stack modal (status/HP/rank/Select, All-movable/Clear, City
  details), city "Units" tab, Statistics modal with 14 Civ1 demographic
  metrics and world ranks, end-of-game overlay with skip setting, minimap,
  camera glides, animations, modals inventory consistent with
  `doc/MODALS.adoc`.
* Auto end turn: checkbox + first-timer offer (turn 15); an automatic
  end-of-turn waits 3 seconds so the player can see the board before the next
  civ takes over (`App.tsx:531-536`).
